# Banques d'échantillons

## acoustic-steel.sf2

Guitare folk à cordes acier, jouée par l'application pour le son `acoustic`
(programme General MIDI 25, banque 0).

- Source : « Acoustic Guitar » par Daindune, https://musical-artifacts.com/artifacts/6136
- Licence : Creative Commons Attribution 3.0 (CC BY 3.0)
- Modification : les paires stéréo gauche/droite ont été mixées en mono
  (moitié de la taille, l'application joue chaque note sur un seul canal).
